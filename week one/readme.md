# AI Image Viewer with Sound Effects

## Project Overview

In this project, you will build an AI-themed image viewer with sound effects using the Pygame library. The application will display a collection of related images while playing a looping sound that matches the visual theme.

This project practices combining visual and audio elements in a Python multimedia application. You may reuse and improve your previous image application or create a new viewer from scratch.

## Learning Goals

- Use Pygame to create a multimedia application.
- Display and move between multiple images.
- Load and play an MP3 sound file.
- Loop background audio while the viewer is running.
- Improve the user experience with text, controls, and volume settings.
- Organize and clearly comment Python code.

## Project Requirements

### Required Features

1. Install Pygame if it is not already installed:

   ```bash
   pip install pygame
   ```

2. Create or reuse an image viewer application.
3. Choose one consistent theme for the project.
4. Collect at least four AI-generated images related to the theme.
5. Add at least one related `.mp3` sound file.
6. Display all four images and allow the user to move through them.
7. Load and play the sound when the first image is displayed.
8. Repeat the sound continuously using a loop.
9. Provide a user-friendly experience.
10. Include detailed comments throughout the source code.

### Optional Enhancements

- Display the current image filename in the Pygame window.
- Display the current sound filename in the Pygame window.
- Add a title or description for the selected theme.
- Allow the user to adjust the sound volume with Pygame's `mixer.music` module.
- Add keyboard controls for moving forward and backward through the images.

## Suggested Theme

For example, use a relaxing rain theme:

- Four AI-generated images of rainy landscapes or city scenes.
- One rain sound effect or rain music track.
- A looping background sound while the images change.

You may choose a different theme as long as the images and sound are related.
